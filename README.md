### Executive Profile

Senior Full-Stack & Applied AI Engineer specializing in architecting production-grade enterprise platforms, high-conversion creative landing pages, and customized machine learning model training pipelines.

Key engineering capabilities include:

* **Creative Web Engineering & High-Converting Landing Pages**: Crafting award-winning, interactive digital experiences utilizing **Next.js 15 (App Router, Server Components), React 19, Three.js, WebGL, GSAP ScrollTrigger, and Lenis Smooth Scroll**. Focused on strict design systems, micro-interactions, sub-second Core Web Vitals, and conversion rate optimization (CRO).
* **Enterprise Modular Backend & Microservices**: Designing distributed architectures with **NestJS (TypeScript)** and **Java Spring Boot 3**. Deep experience with Domain-Driven Design (DDD), Event-Driven Architecture, CQRS, transactional consistency, and high-throughput concurrency using Redis, Apache Kafka, and message queues.
* **Applied Machine Learning & Custom Model Training**: Developing and fine-tuning custom models using **PyTorch, Hugging Face Transformers, LoRA, and QLoRA**. Implementing Retrieval-Augmented Generation (RAG) with vector databases (Qdrant, Milvus), multi-agent systems, and deploying low-latency LLM inference engines (vLLM, Ollama).
* **High-Throughput Automation & Data Engineering**: Building resilient headless browser worker clusters (Playwright, Puppeteer) with advanced anti-detection techniques (canvas and WebGL fingerprint spoofing, natural human cadence simulation) and distributed task queues.
