### About Me

I am a **Full-Stack Software Engineer** focused on building production-grade enterprise applications, high-throughput backend services, and high-performance modern web platforms. 

My engineering background spans across:
* **Enterprise Backend & E-Commerce**: Java Spring Boot, microservices architecture, third-party API synchronization (Shopee Open API), relational database design (MySQL, PostgreSQL), and secure authentication (JWT, RBAC).
* **Modern Frontend & Creative Engineering**: Next.js 16 App Router, React 19, TypeScript, state management, and fluid motion design with GSAP and Lenis.
* **Automation & Data Processing**: Task schedulers, batch content syndication, and NLP sentiment analysis with Python.
